
# StudyFlow - Student Task Manager

GMIU Cloud Computing Practical

## Features
- Add and delete study tasks
- Set subject, due date and priority
- Mark tasks complete
- View task statistics
- Flask application with JSON file storage
- AWS EC2 hosting and Amazon S3 storage demonstration

## Run locally
1. Install Python 3.10 or later.
2. Run `python -m venv .venv`
3. Activate the environment.
4. Run `pip install -r requirements.txt`
5. Run `python app.py`
6. Open http://127.0.0.1:5000
